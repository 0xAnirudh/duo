Numbers, not adjectives

Every figure above was measured on the relay path. Two devices that can reach each other skip the relay entirely and talk over an encrypted peer connection, which should be faster again — that one has not been measured across two machines yet, so it is not quoted here. When the direct path cannot be established, it falls back to the relay without dropping a command.

Install it in two minutes

Not on a store yet, so it loads unpacked. Works in Chrome, Brave, Edge, Arc and anything else built on Chromium.

Get the extension

One 87 KB zip. A relay is already running, so there is no server to set up and nothing to sign into.
